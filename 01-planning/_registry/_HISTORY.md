# 기획 변경 이력

## 2026-11-14 · 행사 안내 템플릿의 작성 내용 순서 변경

- 행사 안내 템플릿의 `{{notice}}`를 일정·참여 안내 정보 상자보다 위로 이동해 다른 행사 상태 템플릿과 같은 본문 → 정보 구조로 통일
- 이전 기본 HTML·텍스트 템플릿은 새 순서로 한 번 갱신하고 운영자가 직접 수정한 템플릿은 보존
- 기본 예시 메일 이력도 새 템플릿 순서로 재생성
- 검증: 린트·타입·행사 테스트·프로덕션 빌드 통과. 메일 미리보기에서 작성 내용 1건이 참여 안내 1건보다 먼저 표시되는 것 확인. 커밋·푸시·PR 준비 없음

## 2026-11-14 · 자동 확정 방식 보조 문구 제거

- `신청하면 바로 참가가 확정돼요` 제목은 유지하고 `신청을 마치면 참여 안내를 확인할 수 있어요.` 보조 문구 제거
- 운영진 확인 방식의 이메일 안내 문구는 유지
- 검증: 린트·타입·프로덕션 빌드 통과. 브라우저에서 자동 확정 제목 1건·삭제 문구 0건 확인. 커밋·푸시·PR 준비 없음

## 2026-11-14 · 운영진 확인 방식 안내 문구 축약

- `운영진 확인 후 참가가 확정돼요` 아래 설명을 `신청 내용을 확인한 뒤 이메일로 알려드려요.`만 남기도록 축약
- 검증: 린트·타입·프로덕션 빌드 통과. 브라우저에서 제목과 남긴 문장 각 1건, 삭제 문장 0건 확인. 커밋·푸시·PR 준비 없음

- 검증: 린트·타입·프로덕션 빌드 통과. 브라우저에서 참가 확정 배지·내 신청 내역은 유지하고 중복 문구 0건 확인. 커밋·푸시·PR 준비 없음
