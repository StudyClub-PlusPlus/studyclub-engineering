# POL-0005 · 닉네임

> 시행일: 2026-09-22 · 적용: 온보딩 · 프로필 수정
> 백엔드 대응: [`specs/user-onboarding/spec.md`](../../../specs/user-onboarding/spec.md) · [`docs/erd/ACCOUNT.md`](../../../docs/erd/ACCOUNT.md)

## 값 규칙

| 항목 | 값 |
|---|---|
| 길이 | 앞뒤 공백을 뗀 뒤 2~20자 |
| 허용 문자 | 모든 언어의 글자 · 숫자 · 밑줄(`_`) |
| 금지 | 공백 · 줄바꿈 · 이모지 · 그 밖의 특수문자, 밑줄만으로 구성 |
| 금지 이름 | `운영진`·`관리자`·`admin` 등 공식 계정으로 오해할 이름, `account_` 접두사 |
| 중복 | 불가. 영문 대소문자를 구분하지 않는다 |
| 정규화 | 앞뒤 공백 제거 → NFC → 소문자. **비교는 정규화 값, 저장은 입력 그대로** |

## 검사 방식

- 입력이 멈추고 **400ms** 뒤에 서버에 묻는다. 한글 조합 중에는 묻지 않는다
- 먼저 온 요청은 취소한다 — 늦게 도착한 옛 답이 화면을 덮지 않게
- **제출할 때 서버가 다시 본다.** 화면 검사는 안내일 뿐이다
- **지금 쓰고 있는 자기 닉네임은 중복으로 보지 않는다** (프로필 수정)
- 가입과 프로필 수정이 **같은 규칙**을 쓴다. 한쪽만 다르면 두 화면이 다른 말을 하게 된다

## 화면 문구

| 상태 | 문구 |
|---|---|
| 기본 | 2~20자 · 한글, 영문, 숫자, 밑줄(_) |
| 허용되지 않은 문자 | `'!'`는 사용할 수 없는 문자입니다 (3개까지 나열, 4개 이상이면 「사용할 수 없는 문자가 포함되어 있습니다」) |
| 공백 | 공백은 사용할 수 없습니다 |
| 이모지 | 이모지는 사용할 수 없습니다 |
| 2자 미만 | 2자 이상 입력해 주세요 |
| 확인 중 | 확인 중입니다 |
| 사용 가능 | 사용할 수 있는 닉네임입니다 |
| 중복 | 이미 사용중인 닉네임입니다 |
| 검사 실패 | 확인하지 못했습니다. 다시 시도해 주세요 |
