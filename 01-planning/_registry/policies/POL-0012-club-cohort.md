# POL-0012 · 클럽 기수

> 시행일: 2027-01-01 (1월 기수부터) · 적용: 운영 콘솔 › 클럽 운영, 사용자 사이트 클럽 신청
> 백엔드 대응: [`specs/club-cohort/spec.md`](../../../specs/club-cohort/spec.md)

클럽은 같은 프로그램(`STUDY_PROGRAM.STUDY_KIND = CLUB`) 아래 기수가 매달 이어지는 모임이다.
지금 클럽은 얼리버드 · WEEKLY X · Daily LeetCode 셋이다.

## 기수는 달 하나다

- 기수 기간은 **그 달 1일 0시 ~ 말일 24시**다. 주 단위로 나누지 않는다
- 한 클럽에 같은 달 기수는 **하나뿐**이다
- 기수 제목은 「{클럽 제목} {YYYY}년 {M}월」이다 — 예: 「얼리버드 2027년 1월」
- 클럽 기수에는 분반이 없다. 기본 반 하나에 모두 들어가고, 화면에 반을 드러내지 않는다

## 다음 기수 — 초안은 자동, 모집은 캡틴

- 클럽마다 **자동 초안**을 켜고 끌 수 있다. 기본은 켜짐, 만드는 날은 **매월 15일**이다 (1~28일 중 고른다)
- 그날 0시(캡틴 시간대)에 다음 달 기수를 **미공개(`DRAFT`)** 로 만든다. 이미 다음 달 기수가 있으면 만들지 않는다
- 초안은 이번 기수의 소개 · 상세 설명 · 카테고리 · 디스코드 채널 · 드라이브 · 정원 · 신청 폼을 복사한다. 복사한 값을 고쳐도 이번 기수는 그대로다
- 모집 마감은 **이번 달 말일 23:59**(캡틴 시간대)다
- 캡틴이 **「모집 시작」** 을 눌러야 공개된다. 누른 날이 모집 시작일이다. 공개 조건은 스터디 공개와 같다 ([POL-0003](POL-0003-study-fields.md))
- 자동 초안을 기다리지 않고 캡틴이 먼저 만들 수 있다. 내용은 자동 초안과 같다
- 예약 공개 없음

## 이어서 참여 — 끝까지 남은 사람은 다음 달로

- 이번 기수가 끝날 때 **참여 중(`ACTIVE`)** 인 사람은 다음 기수 시작일 0시에 다음 기수 참여자가 된다
- 기수 중에 참여 중단(`WITHDRAWN`)한 사람은 넘어가지 않는다. 다시 하려면 다음 모집에 신청한다
- 캡틴은 다음 기수 시작 전까지 넘기지 않을 사람을 **뺄 수 있다**. 뺀 사람도 다음 모집에 직접 신청할 수 있다
- 넘어가는 사람의 클럽 신청 값(기상 목표 시각 · LeetCode ID)은 다음 기수로 이어진다
- 넘어갈 인원은 다음 기수 정원에 포함된다. 남은 자리 = 정원 − 넘어갈 인원 − 신청 인원
- 넘어갈 사람이 다음 기수에 신청하면 참여자는 한 명이다 — 신청이 이긴다 (신청 답변으로 바꾼다)

## 출석 — 날마다, 출석 여부만

- 출석부의 칸은 **참여자 × 날짜**다. 클럽은 모임 시각이 없다
- 출석은 캡틴이 입력한다. R1 동안 시트 · 디스코드 기록과 함께 쓴다
- 클럽마다 쓰는 값

  | 클럽 | 출석 값 | 신청 때 받는 값 |
  |---|---|---|
  | 얼리버드 | 출석 · 지각 · 결석 · 휴가 | 기상 목표 시각 (필수) |
  | WEEKLY X | 출석 · 결석 · 휴가 | — |
  | Daily LeetCode | 출석 · 결석 · 휴가 | LeetCode ID (필수) |

- 지각은 0.5일로 센다
- 출석률 = (출석 + 지각 × 0.5) ÷ (기록된 날 − 휴가). 기록 없는 날은 분모에 넣지 않는다
- Daily LeetCode 의 날짜는 **UTC 날짜**다 (한국 시간 오전 9시에 바뀐다). 나머지 클럽은 참여자의 날짜다
- 오늘 뒤의 날짜, 참여 중단한 날 뒤의 날짜는 입력할 수 없다

## 완주

- 기수가 끝날 때 참여 중단되지 않은 사람은 **완주(`COMPLETED`)** 다
- 제명 기준은 클럽마다 다르고 시스템이 판정하지 않는다. 캡틴이 출석부에서 참여 중단한다
