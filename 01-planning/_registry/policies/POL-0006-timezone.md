# POL-0006 · 시간대와 지역

> 개정: 2026-11-22 · 기획 목표 정책. 현재 beta 구현과의 차이는 통합 PRD §8을 참고한다.
> 정본: [전 세계 시간대 확장 PRD](../../stories/timezone-expansion/PRD.md)
> 저장 필드: [ACCOUNT.TIME_ZONE](../../../docs/erd/ACCOUNT.md). 기존 4개 선택지·한국 외 북미 파생 정책을 이 개정으로 대체한다.

## 값의 구분

- 회원 시간대는 **표시 기준**이다. 거주 국가·국적을 확정하거나 기존 신청 답변·반 배정을 바꾸지 않는다.
- 기존 모집 값은 배포 전 PST→LA, BOTH→한국+LA로 이관한다. 이미 저장된 IANA 지역은 유지한다.
- 모집 시간대는 안내/검색 범위다. 미정·모든 시간대·특정 지역 목록을 구분하고, 반 기준 시간대와 독립시킨다.
- 반/행사 기준 시간대는 일정 입력·반복 생성 기준이다. 반복은 그 지역의 현지 요일·시각을 유지한다.
- 백오피스 표시 시간대는 헤더에서 운영자별로 설정한다. 회원 프로필과 별도로 유지한다.
- 저장은 IANA ID, 실제 순간은 UTC다. 같은 오프셋의 지역이라도 서로 다른 IANA ID를 합치지 않는다.

## 선택기·집계

- 전체 선택기는 국가별 검색·주요 국가/도시 우선. 회원 수 제한은 헤더·모집 선택기의 기본 후보에만 적용한다. 둘 다 전체 지역 검색으로 확장할 수 있고 회원 수와 무관하게 기존 선택을 유지한다.
- 후보는 가입 완료·비탈퇴 전체 회원, 프로필 변경 후 페이지 재진입·새로고침에서 갱신한다.
- 전체/미정/특정 모집 모드, OR 검색, 기존 선택값·빈 후보·실패 처리는 [확장 PRD §2–4](../../stories/timezone-expansion/PRD.md)를 따른다.

## 날짜·시간 표시와 입력

- 회원 조회는 프로필 → 기기 → 한국, 백오피스 조회는 공통 헤더 기준이다. 사용자 사이트의 캡틴·네비게이터는 회차 표의 조회·직접 수정 시간대만 임시 전환할 수 있다([회차 등록 PRD §8](../../stories/navigator-register-sessions/PRD.md#8-시간대)).
- 모든 구조화된 시각은 24시간제와 해당 날짜의 약칭을 사용한다. 약칭이 없으면 UTC 오프셋. 날짜 없는 지역 선택에 현재 DST 약칭을 고정 저장하지 않는다.
- 모집 일정 자유 문구는 자동 변환하지 않는다. ‘내 시간대’로 환산한 가상 확정 일정 예시는 사용하지 않는다.
- 반/회차 신규 입력은 반 기준, 행사 입력은 행사 기준이다. 입력 아래에는 사용자 사이트에서 프로필 → 기기 → 한국, 백오피스에서 헤더 기준으로 환산한 값을 보여주고 같은 기준이면 생략한다.
- 백오피스 개별 회차 직접 편집은 헤더 기준으로 입력한다. 편집 중 헤더 변경을 막아 해석 기준을 보존한다.
- 반복 기간 중 두 지역의 시차가 실제 달라질 때만 변환 시각 변화를 안내한다.
- DST로 없는 시각은 저장 차단, 두 번 존재하는 시각은 전환 전/후 명시적 선택. 기존 값을 그대로 되돌리면 원래 UTC 순간을 유지한다.
- 출석 판정·하루 한 회차·킥오프 순서 등 반 단위 검증은 반 시간대를 따른다. 반복 기간 상한은 기존 1년 규칙을 유지한다.
- 밴쿠버와 LA는 별도 지역이다. 저장 ID를 유지하며 기존 밴쿠버 2026-03-08 이후 UTC−7/PCT 호환 처리는 보존한다. 브라우저와 서버의 지역 규칙 일치 여부를 검증한다.

## 모집 마감

- 하나의 UTC 순간에 전 지역이 함께 마감된다. 현재 시각 ≥ 마감 시각이면 마감. 서버가 신청 가능 여부를 최종 판정한다.
- 날짜 입력은 입력 당시 헤더 지역의 23:59:59로 환산한다. 미수정 마감·표시 시간대 변경은 저장 UTC를 바꾸지 않는다.
- D-day는 조회자의 달력 날짜 차이이며 마감 판정에 사용하지 않는다. 마감된 경우 D-day보다 ‘모집 마감’을 우선한다.
- 날짜 전용 레거시는 원본 기준을 확인하기 전 임의로 변환하지 않는다. 플레이그라운드의 명시적 KST 표본과 실제 이관은 다르다.

## 집계 경계

- 시간대 분포는 기존 활동 크루 대상이며 헤더 후보의 전체 회원 집계와 구분한다. 5개 초과는 상위 4개+기타. 실제 누락은 미설정으로 별도 표시한다.
- 운영 대시보드의 주간 출석 집계는 **헤더 시간대**의 월요일 00:00 경계를 사용한다. 헤더 변경 시 표시뿐 아니라 이 집계도 다시 요청한다.
- 다른 주별 집계의 기존 한국 경계는 유지한다. 표시 기준을 바꿨다고 판정·집계 기준 전체를 변경하지 않는다.
- 실제 통계 계산은 서버에서 수행한다. Playground는 화면 검토용 표본 집계다.
