# POL-0004 · 신청

> 백엔드 대응: [`docs/erd/STUDY_APPLICATION.md`](../../../docs/erd/STUDY_APPLICATION.md) · [`specs/study-recruit-status/spec.md`](../../../specs/study-recruit-status/spec.md)

## 신청은 상태를 갖지 않는다

**행이 있으면 제출 완료다.** 승인·거절·검토·대기 상태를 두지 않는다.

- 캡틴이 신청을 심사해 받아들이는 단계가 없다 — 신청하면 참여다
- 그래서 「승인 대기」·「거절됨」 같은 화면 상태도 없다
- 취소도 상태가 아니다. 참여를 그만두는 것은 명부(`STUDY_PARTICIPANT`) 쪽 일이다

## 판정 규칙

| 무엇 | 규칙 |
|---|---|
| 신청할 수 있는 조건 | 기수가 공개(`OPEN`) + 모집 기간 안 + 로그인 + 같은 모집 회차에 신청 행 없음 |
| 한 기수에 몇 번 | 한 번. 중복 신청은 받지 않는다. 기수 하나에 모집이 하나라 「모집 회차마다 한 번」과 같은 말이다 ([POL-0002](POL-0002-study-status.md)) |
| 정원 판정 | 기수 명부의 **활성 인원** 기준. 가득이면 저장하지 않는다 |
| 반별 정원 | 신청 검사에 넣지 않는다 — **반은 신청 이후에 정해진다** |
| 대기열 | 두지 않는다 |
