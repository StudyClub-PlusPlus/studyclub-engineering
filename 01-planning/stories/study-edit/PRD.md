# 캡틴은 등록된 스터디를 수정·삭제할 수 있다.

기준 프로토타입: 운영 콘솔 › 스터디 › 스터디 상세 › 정보 탭 — https://playground.studyclub-plusplus.com/proto/console/studies

## 1. 기본설명

### 완료 기준

1. 정보 탭에서 등록 항목 수정
2. 저장 시 사용자 사이트 목록·상세 반영
3. 등록과 같은 검증 — 실패 시 저장 차단 및 칸별 오류
4. 저장 완료 표시
5. 삭제는 확인 후 실행 — 함께 사라지는 것 사전 고지
6. 소속 프로그램 표시 — 연결은 변경 불가

## 2. 화면명세

> **화면**: 운영 콘솔 › 스터디 › 스터디 상세 › 정보 탭

![정보 탭](https://raw.githubusercontent.com/StudyClub-PlusPlus/studyclub-engineering/beta/01-planning/stories/study-edit/assets/info-tab.png)

### 1 — 정보 탭 본문 (입력 폼)
- **내용**: 등록 때와 같은 항목이 저장된 값으로 채워져 열린다
- **동작**: 칸을 고치면 직전 저장 안내가 사라진다
- **정책**
  - **등록 폼을 그대로 편다.** 읽기 화면을 따로 두고 「수정」으로 팝업을 띄우면 같은 정보를 두 가지
    모양으로 보게 된다. 보이는 칸이 곧 고치는 칸이다
  - 항목별 입력 규칙은 [POL-0003 스터디 정보 항목](https://github.com/StudyClub-PlusPlus/studyclub-engineering/blob/beta/01-planning/_registry/policies/POL-0003-study-fields.md)이 정한다.
    이 문서가 다시 정의하지 않는다
  - **날짜 값은 이 탭이 갖는다.** 헤더는 상태만 말한다

#### 1-1 — 프로그램
- **내용**: 이 기수가 어느 프로그램에 속하는가. 종류(스터디·클럽)와 함께
- **동작**: 읽기 전용이다 — 바꿀 수 없다
- **정책**: 프로그램을 옮기면 지난 기수의 이력이 끊긴다. 잘못 묶였으면 지우고 다시 만든다

#### 1-2 — 카테고리
- **내용**: 고른 하나가 드러난다
- **정책**: **스터디마다 하나다** ([POL-0003](https://github.com/StudyClub-PlusPlus/studyclub-engineering/blob/beta/01-planning/_registry/policies/POL-0003-study-fields.md))

#### 1-3 — 상세 설명
- **동작**: 마크다운을 쓸 수 있고, 쓸 수 있는 문법을 칸 아래에 적는다
- **정책**: 목록 카드에는 나오지 않는다. 스터디 상세에서만 쓴다

#### 1-4 — 모집 정원
- **동작**: 「제한 없음」을 켜면 칸이 잠기고 값이 지워진다
- **정책**: 기수 전체 정원이다. 반별 정원은 반이 갖는다

### 2 — 저장
- **동작**
  - 검증 통과 → 저장 → 「저장되었습니다.」
  - 검증 실패 → 해당 칸에 오류, 저장 안 함
  - 처리 중 → 버튼 비활성 (중복 제출 차단)
- **정책**
  - 검증 규칙은 등록과 같다
  - 검토·승인 단계 없이 즉시 반영된다
  - 마감일을 고치면 헤더의 모집 상태가 함께 바뀐다
- **데이터**: `PATCH /api/admin/studies/{studyId}`
- **정책(보탬)**: 바뀐 칸만 보낸다. 마감이 지난 스터디에서 지난 마감일을 다시 보내지 않는다 — 마감이 지나도 다른 칸은 고칠 수 있다

### 3 — 스터디 삭제
- **내용**: 저장 버튼과 **반대편 끝**
- **동작**: 누르면 확인 창이 뜬다. 그 자리에서 지워지지 않는다
- **정책**: 삭제를 저장과 멀리 떨어뜨린다 — 잘못 누르면 되돌릴 수 없다

### 4 — 삭제 확인 창
- **내용**: 지울 스터디 이름을 그대로 적고, 함께 사라지는 것을 밝힌다 — **크루 명단과 출석 기록**
- **동작**
  - 취소 · 배경 클릭 · Esc → 아무것도 지우지 않고 닫힌다
  - 삭제 → 스터디가 사라지고 목록으로 돌아간다
- **정책**
  - **함께 사라지는 것을 명시한다** — 스터디만 지워진다고 오해하면 복구 요청이 들어온다
  - 되돌릴 수 없다는 것을 문구로 알린다
- **데이터**: `DELETE /api/admin/studies/{studyId}`

### 상태별 화면

| 상태 | 화면 | 카피 |
|---|---|---|
| 기본 | 저장된 값이 채워진 폼 | — |

| 삭제 확인 | 확인 창 | 「'{스터디명}' 스터디를 삭제합니다.」 / 「크루 명단과 출석 기록도 함께 사라지며 되돌릴 수 없습니다.」 |

### 비고

- **범위 밖** — 스터디 등록 · 신청 폼 편집 · 신청자 명단 · 출석 체크 · 반 편성 (각각 별도 Story)
- **미구현** — 저장·삭제가 화면 상태로만 동작한다. 새로고침하면 되돌아간다
- **미구현** — 저장 실패·권한 없음 화면. API 연동 시 함께 정의한다

## 3. 시스템 요건

### 데이터

수정 대상은 등록과 같다. 이 Story 가 새로 만드는 필드는 없다.

| 필드 | 수정 | 비고 |
|---|---|---|
| title · oneLineSummary · description · category · schedule · timezone · thumbnail | 가능 | 등록과 같은 제약 ([POL-0003](../../_registry/policies/POL-0003-study-fields.md)) |
| recruitDeadline · capacity | 가능 | 최신 모집 회차만. 바꾸면 모집 상태가 따라 바뀐다 |
| startAt · discordChannelUrl · driveUrl | 가능 | `null` 이면 비우고, 키가 없으면 그대로 둔다 |
| studyProgramId · studyKind | 불가 | 기수가 속한 프로그램·종류는 바뀌지 않는다 |
| status | 불가 | 공개 API 로만 바꾼다 |
| createdBy | 불가 | 등록자는 바뀌지 않는다 |

- 고칠 수 있는 필드: title · oneLineSummary · description · category · recruitDeadline · capacity · schedule · timezone · startAt · discordChannelUrl · driveUrl
- 고칠 수 없는 필드: studyProgramId · studyKind · status (상태는 공개 API 로만 바꾼다)
- recruitDeadline · capacity 는 id 가 가장 큰(최신) 모집 회차만 고친다
- `null` 과 키 생략을 구분한다. capacity · startAt · discordChannelUrl · driveUrl 은 `null` 이면 비우고, 키가 없으면 그대로 둔다

### 처리

- 수정: 보낸 필드만 반영한다. 검증은 등록과 같다. recruitDeadline 은 null 불가, 보내면 미래여야 한다
- 삭제: 물리 삭제. 스터디와 모집 회차 · 신청 · 반 · 명부 · 출석을 함께 지운다. 같은 프로그램의 다른 기수와 프로그램은 남는다
- 실패: 400 `INVALID_INPUT` (필드명: 사유) · 401 · 403 · 404

### API

| 메서드 | 경로 | 권한 |
| --- | --- | --- |
| PATCH | `/api/admin/studies/{studyId}` | 캡틴 (운영 콘솔) |
| DELETE | `/api/admin/studies/{studyId}` | 캡틴 |

네비게이터의 수정은 사용자 사이트 경로(`PATCH /api/studies/{studyId}`)가 따로 받는다 — 로직은 같고 권한만 다르다.

계약은 [study/spec.md](../../../specs/study/spec.md#스터디-수정).

### 권한

- 수정: 캡틴, 그 스터디의 네비게이터. 서버에서 검증한다 — 맡은 스터디를 굴리는 데 필요하다 ([POL-0001](../../_registry/policies/POL-0001-roles.md))
- 삭제: 캡틴만. 크루 명단·출석까지 사라지므로 되돌릴 수 없다

### 외부 연동

- 없음
