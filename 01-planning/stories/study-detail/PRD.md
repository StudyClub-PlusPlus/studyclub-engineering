# 캡틴은 개별 스터디의 운영 현황을 볼 수 있다.

기준 프로토타입: 운영 콘솔 › 스터디 › 스터디 상세 — https://playground.studyclub-plusplus.com/proto/console/studies

## 1. 기본설명

### 하는 일

- 스터디 하나가 지금 어떻게 굴러가는지를 한 화면에서 확인한다
- 손을 써야 하면 그 자리에서 해당 탭으로 들어간다

### 완료 기준

1. 상단에서 스터디명·모집 상태 확인 — 남은 일수 포함
2. 미공개 스터디는 상단에 그 사실 표기
3. 정보·신청 폼·신청 결과·신청자·출석 다섯 탭 전환 및 현재 위치 표시
4. 출석 탭 미저장 변경 시 탭 이동 전 경고
5. 클럽은 이 화면에서 다음 기수 생성
6. 목록으로 돌아가기

---

## 2. 화면명세

> **화면**: 운영 콘솔 › 스터디 › 스터디 상세

![스터디 상세](https://raw.githubusercontent.com/StudyClub-PlusPlus/studyclub-engineering/beta/01-planning/stories/study-detail/assets/detail-header.png)

### 1 — 헤더
- **내용**: 스터디명과 **지금 신청을 받는가**, 그리고 **사이트에 보이는가**
- **정책**
  - **헤더는 상태만 말한다.** 날짜 값은 정보 탭이 갖는다 — 같은 값을 두 곳에 두면 어느 쪽이 정본인지
    매번 헷갈리고, 고칠 때 한 곳만 고치게 된다
  - 지표 카드를 두지 않는다. 참석자는 신청자 탭이, 출석률은 출석 탭이 이미 말한다

#### 1-1 — 스터디명
- **데이터**: 기수 제목 (운영 콘솔은 한국어 고정)

#### 1-2 — 모집 상태 · 공개 상태
- **내용**
  - 모집중이면 **남은 일수까지** — 「모집중 · D-4」, 당일이면 「오늘 마감」, 지났으면 「모집 마감」
  - 미공개면 그 사실을 함께 — 사이트에 보이지 않는다는 뜻이다
- **정책**
  - 마감까지 남은 날은 상태의 일부다 — 날짜를 보려고 탭을 옮기게 하지 않는다
  - 모집 상태는 **한 곳에서만 계산한다** — 사용자 사이트와 판정이 갈리면 안 된다 ([POL-0002](https://raw.githubusercontent.com/StudyClub-PlusPlus/studyclub-engineering/beta/01-planning/stories/../_registry/policies/POL-0002-study-status.md))

#### 1-3 — 다음 기수 만들기
- **조건**: 클럽일 때만
- **동작**: 누르면 같은 프로그램의 새 기수를 만든다
- **정책**: 기수를 잇는 것은 클럽뿐이다 — 스터디는 기수가 하나라 새 공고가 곧 새 프로그램이다

### 2 — 탭
- **내용**: 정보 · 신청 폼 · 신청 결과 · 신청자 · 출석. 지금 보고 있는 탭이 드러난다
- **동작**
  - 탭을 옮기면 본문만 바뀌고 헤더는 남는다
  - **출석 탭에 저장하지 않은 변경이 있으면** 탭 이름 옆에 그 사실을 알리고, 옮기기 전에 한 번 묻는다
- **정책**: 캡틴이 한 스터디에서 하는 일이 다섯이라 탭도 다섯이다 — 무엇을 알리는가 · 무엇을 묻는가 ·
  무엇이 들어왔는가 · 누가 들어오는가 · 누가 나오는가

### 상태별 화면

| 상태 | 화면 |
|---|---|
| 모집중 | 헤더에 「모집중 · D-N」 |
| 오늘 마감 | 헤더에 「오늘 마감」 — 아직 신청을 받는다 |
| 모집 마감 | 헤더에 「모집 마감」 |
| 미공개 | 모집 상태 옆에 「미공개」 |
| 출석 저장 전 | 출석 탭 이름 옆에 「저장 전」 |

### 비고

- **범위 밖** — 각 탭의 내용(신청 폼 편집 · 신청 결과 · 신청자 명단 · 출석 체크)과 정보 수정·삭제는
  각각 별도 Story
- **미구현** — 서버 집계. 지금은 mock 에서 계산한다

## 3. 시스템 요건

### 데이터

| 값 | 출처 | 비고 |
|---|---|---|
| 스터디명 | 기수 제목 | 그대로 표시 |
| 모집 상태 | 마감일·정원으로 계산 | 저장하지 않는다 ([POL-0002](https://raw.githubusercontent.com/StudyClub-PlusPlus/studyclub-engineering/beta/01-planning/stories/../_registry/policies/POL-0002-study-status.md)) |
| 공개 상태 | 기수 상태 | 미공개면 사이트에 보이지 않는다 |
| 클럽 여부 | 프로그램 종류 | 다음 기수 만들기를 띄울지 가른다 |

### API · 권한

| 메서드 | 경로 | 권한 |
|---|---|---|
| GET | `/api/admin/studies/{studyId}` | 캡틴 (운영 콘솔) ([POL-0001](../../_registry/policies/POL-0001-roles.md)) |
| GET | `/api/studies/{studyId}` | 그 스터디의 네비게이터 — 사용자 사이트 경로. DRAFT 도 본다 |

계약은 [study/spec.md](../../../specs/study/spec.md).

- 네비게이터는 맡은 스터디를 굴려야 하므로 현황을 볼 수 있어야 한다. 남의 스터디는 열리지 않는다
