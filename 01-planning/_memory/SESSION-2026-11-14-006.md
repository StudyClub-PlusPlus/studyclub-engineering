- 확정 방식을 신청 즉시 확정으로 변경하면 기존 확인 대기 신청을 참가 확정하고 각 신청자 확정 메일 이력을 생성
- 운영진 확인 방식으로 되돌려도 처리 완료 상태는 유지하고 이후 신청만 확인 대기로 접수
- 확정 방식 변경은 행사 시작 전만 허용. 시작 시간을 현재 이전으로 당기면서 함께 변경하는 우회도 차단
- 공개 여부·신청 이력과 관계없이 질문 편집 가능. 기존 신청서는 당시 질문·답변, 새 신청은 최신 질문 사용
- 열려 있던 신청폼의 삭제 질문·선택지 답변은 최신 폼에 맞춰 정리하고 제출 경계에서도 한 번 더 제거
- 빌드·타입·린트·행사 상태 전이·명세 동기화·부품 드리프트·개발 범위·diff 검사 통과. 브라우저에서 새 안내 문구와 확정 방식·질문 입력 활성화 확인
- 독립 검토 L1/L2/L3에서 발견한 시작 시각 동시 변경, 열린 폼 답변 잔존, 신규 행사 속성 경계를 보완
