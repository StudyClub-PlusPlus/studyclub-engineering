## 1. 의도

가입을 먼저 완료한 뒤 디스코드 연결을 선택하고, 스터디 신청 시 필수 연결을 확인하는 시안 반영. 참여 중 연결 해제 차단에 해결 안내 추가. 최신 beta에서 codex가 없는 이름으로 새 브랜치 생성 요청.

## 2. 판단

- beta d74c6c84에서 연결 API 구현 및 내 정보의 discordLinked 확인. discordHandle 응답과 해제 API는 미구현.
- Playground의 기존 연결 버튼과 신청 게이트 재사용. 실제 API·core-front는 변경 범위에서 제외.
- 내 스터디룸에는 직접 참여 중단 기능이 없어, 스터디 확인 링크와 운영진 문의 안내 병기.
- 참여 차단은 기존 lifeStatus의 시작 전·참여 중을 사용. 서버의 휴식 상태 등 상세 매핑은 API 담당자 확인 대상으로 보존.
- 연결 게이트 화면 명세를 별도 spec.ts로 분리하여 PRD 자동 반영. 기존 exporter의 동명 동적 라우트 캐시 충돌을 피하며 다른 화면 문서 변경은 제외.
