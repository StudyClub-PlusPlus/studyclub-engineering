## 1. 요청과 범위

운영 목록과 설명 문구 간소화, 행사 종료 선택 입력, 신청 후 모집 설정 변경, 실제 메인 디스코드 사례 기반 예시. 개인 이름은 가명으로 변경. 커밋과 PR은 하지 않음.

## 2. 반영

- 목록은 행사·일정·상태만 표시. 운영 화면의 행사 시안 바와 요청한 설명 문구 제거
- 종료 미입력 가능. 확정 방식은 새 신청부터 적용하며 기존 상태 유지. 활성 신청자가 있는 참여 방식을 없애는 변경만 제한
- 참가 불가를 신청 거절, 신청 취소를 취소 처리로 표현. 메일 미리보기 탭은 메일 이력으로 변경
- 실제 강연·강화학습 특강·피크닉 운영 사례를 참고하고 일정·신청자는 체험용으로 설정. 연사는 코드별, 참가자는 가상 닉네임 사용
- 기존 알림 템플릿 관리에 행사 안내 HTML 공통 프레임 하나 등록. 행사 작성창에서 내용만 입력하고 미리보기는 notice만 채워 나머지 변수를 원문 유지. 참가자 선택 제거
- 확정자가 없어도 미리보기 가능. 보내기는 확정자가 있어야 하며 개인별 치환 결과를 이력에 보관. 실제 발송 없음
- 템플릿 전체 브라우저 저장, 다른 탭 동기화, 과거 일반 텍스트 이력 형식 보존

## 3. 검증

- 독립 검토 L1/L2/L3 합격(R6)
- build(타입 검사 포함), lint, test:events, export-specs --check, component-drift, check-dev-scope 통과
- 공통 HTML이 standalone 산출물에 포함됨 확인
- 브라우저: 저장된 예시 가명 전환, 변경 후 기존 신청 상태 유지, 활성 참여 방식 제거 차단, 종료 빈값 저장, 템플릿 수정·새로고침·다른 탭 동기화, 내용만 합친 HTML 미리보기, 대상 0명 미리보기와 발송 차단, 375px 가로 넘침 없음
- 기존 proto.css의 @source 빌드 경고는 동일

## 4. 남은 실제 개발

행사 API 계약, 서버 권한·정원 동시성, 실제 메일 발송·저장과 개인정보 보유 정책. 이번에는 실제 서비스와 DB를 수정하지 않음. 현재 브랜치에 미커밋 변경으로 유지.
