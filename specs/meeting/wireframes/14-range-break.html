14 · 여러 주 쉬기 — 기간으로 고른다조합 A5 · B5 · E5. WEEKLY X 12월 기수의 연말 방학 12/21 ~ 12/31. 칩 11개를 하나씩 누르지 않고 날짜 두 번(시작·끝)으로 고른다.
  • 「기간 선택」 을 켜고 시작 날짜 → 끝 날짜를 누르거나, 달력에서 끌어서 고른다. 고른 기간의 회차가 모두 선택된 상태가 된다 — 이후는 05 여러 개 선택과 같다.
  • API 변경 없음 — 화면이 기간 안 회차 id 를 모아 휴강(PATCH …/meetings) 또는 미루기로 보낸다.
  • 월 기수(끝이 날짜)는 미루면 넘치는 회차가 기수 밖으로 밀려 삭제된다. 이 예처럼 기간이 기수 끝까지 닿으면 휴강과 결과가 같아 미루기를 흐리게 둔다. 월 중간 기간이면 미루기가 켜진다(끝의 회차가 떨어진다). 스터디(끝이 회수)면 미루기가 켜진다.
  • 여러 스터디·클럽을 한꺼번에 방학시키는 건(캡틴) 이 화면 범위 밖 — 결정 필요.
