# 운영 작업 절차 (ops)

**파일 하나 = 일 하나.** 같은 운영 작업을 **두 번째** 하게 되면 여기에 절차로 남긴다. 한 번 하고 마는 일은 쓰지 않는다.
골렘 루틴은 *언제·누가* 만 갖고, 절차는 이 파일을 가리킨다.

## 양식 — `<작업>.md`

```markdown
---
일: prod 배포
언제: main 머지 직후 · 사람이 "배포해" 라고 할 때
권한: (필요한 컨텍스트·역할 — 값은 쓰지 않는다)
사람 승인: 마이그레이션 SQL 실행 전 · 롤백 전
실패하면: docs/incidents/ 에 한 장 쓰고 리드 호출
---
1. …
2. …
```

- 시크릿 **값**은 쓰지 않는다. 어디서 받는지만
- 사고에서 단계가 추가됐으면 그 줄 끝에 `← YYYY-MM-DD 사고에서 추가`
