# 할 일 — 이 레포에서 에이전트·사람이 집어 갈 것

**파일 하나 = 할 일 하나.** 레포를 연 사람이든 Claude·Codex·골렘이든 여기서 집어 간다.
팀에 트래커(zapp·Jira·골렘 이슈)가 있으면 **트래커가 정본**이고 여기는 쓰지 않는다 — 트래커가 없는 레포만 쓴다.

## 양식 — `<slug>.md`

```markdown
---
상태: 열림 | 진행 | 끝남
담당: any | <github id> | golem:<배치>
기한: YYYY-MM-DD (없으면 비움)
근거: PR #NNN · docs/share/...
---
# 한 문장
## 끝났다고 볼 조건
```

끝나면 지우지 않고 `상태: 끝남` + 근거 PR.
