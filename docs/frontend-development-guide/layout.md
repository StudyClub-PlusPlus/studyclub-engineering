# 화면 콘텐츠 폭 규약

페이지마다 폭이 다르면 메뉴를 옮겨 다닐 때 본문이 좌우로 흔들린다. 폭은 아래 넷 중에서만 고른다.
값은 `frontend/apps/core-front/src/lib/layout.ts` 상수로 쓴다. 클래스를 손으로 다시 적지 않는다.

| 상수 | 값 | 쓰는 곳 |
|---|---|---|
| `PAGE` | `mx-auto w-full max-w-6xl px-6` | **모든 페이지의 바깥 틀.** 헤더·푸터와 같은 선 |
| `READ` | `max-w-3xl` | 긴 글을 읽는 단. 공지·약관 본문, 소개 문단 |
| `FORM` | `max-w-2xl` | 입력·설정 단. 마이페이지 폼, 온보딩 |
| `DETAIL_GRID` + `DETAIL_ASIDE` | 2단(본문 + 340px), 오른쪽은 넓은 화면에서 따라온다 | 스터디·행사·공지 **상세** |

## 규칙

1. 바깥 틀은 언제나 `PAGE`. 좁은 화면이 필요하면 바깥을 줄이지 말고 **안쪽 단**을 `READ`·`FORM` 으로 좁힌다
2. 상세 페이지는 같은 구성: 왼쪽 `머리 카드(옅은 바탕 + 배지 + 제목 + 한 줄) → 본문`, 오른쪽 `정보 칸 → 주 행동 버튼`
3. 목록 페이지(스터디·행사·공지)는 `PAGE` 를 꽉 채운다. 카드 그리드는 3열(lg) / 2열(sm) / 1열
4. 좌우 여백은 `px-6` 하나. 375px 에서 가로 스크롤 0
