# 운영 정책

규칙이 **무엇인가**와 **지금 값**을 적는 곳이다. 영역마다 한 파일로 둔다 (`payment.md` · `refund.md` · `settlement.md` · `points.md` …).

| 여기에 쓴다 | 다른 데 쓴다 |
|---|---|
| 수수료율, 환불 기준, 정산 통화·주기, 결제수단별 허용 범위, 한도 — 지금 값과 근거 | 구현 방법 → `specs/<기능>/` |
| 언제·누가·왜 정했나 (결정일·결정자·근거 링크) | 사용자에게 약속한 문구 → 약관·`docs/legal/` |
| 아직 안 정한 것 — `결정 필요` 로 표시 | 왜 만드나 → zapp PRD |

## 파일 한 장의 모양

```markdown
# <영역> 정책

| 규칙 | 지금 값 | 근거 · 결정 | 적용 코드 |
|---|---|---|---|
| … | … | 2026-10-12 · 대표 · PR #… | specs/<기능> §… |

## 결정 필요
- … (지금 임시로 어떻게 동작하나 · 누가 정하나)

## 변경 이력
| 날짜 | 무엇 | 왜 |
```

정책 값을 바꾸면 **같은 PR 에서** 이 파일과 해당 스펙을 같이 고친다.
