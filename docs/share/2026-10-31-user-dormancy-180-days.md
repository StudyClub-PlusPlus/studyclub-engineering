# 180일간 명부 참여와 로그인이 모두 없는 회원만 휴면으로 표시한다

## 미리 알아야 할 것

명부는 스터디에 소속된 사람의 목록이다. 신청서를 제출하면 명부에 들어간다. 휴면은 백오피스 회원 이름 옆에 붙는 안내 표시다.
수업에 등록한 학생과 매번 출석한 학생을 구분하듯, 이번 기준은 실제 출석 횟수가 아니라 명부에 속했던 기간을 본다.

## 정해진 것

- 최근 180일간 명부 참여와 로그인 기록이 **모두 없을 때만** 휴면으로 표시한다.
- 현재 참여 또는 일시 중단한 명부는 참여로 인정한다. 스터디가 종료됐다면 종료일을 기준으로 본다.
- 완주자는 스터디 종료일까지 참여한 것으로 본다. 하차자는 하차일과 스터디 종료일 중 이른 시각까지다. 편입일만 오래됐다고 휴면으로 분류하지 않는다.
- 사용자 사이트와 백오피스의 로그인 기록을 모두 합쳐 가장 최근 시각을 사용한다. 화면 열람이나 로그인 유지용 토큰 갱신을 새 로그인으로 보지는 않는다.
- 캡틴도 같은 기준이다. 가입 후 180일 이내인 신규 회원은 제외한다.
- 판정 시각에서 180 × 24시간을 뺀 경계 시각의 기록도 최근 기록에 포함한다.
- 로그인일·참여 종료일 등 필요한 정보가 없으면 휴면으로 단정하지 않는다. 참여 이력이 없다는 것이 확인된 빈 명부와 이력 미확인은 구분한다.
- 문구는 「휴면」을 유지한다. 설명은 「최근 180일간 스터디 참여 및 로그인 기록이 없는 회원」이다.

## 적용 범위

플레이그라운드에서 확인한 뒤, 2026-11-01 실제 회원 목록 API와 백오피스에도 같은 기준을 구현했다. 예시는 2026-10-31 기준으로 고정했다. 이름·이메일 검색창에 `activity-demo`를 입력하면 다음 가상 회원을 모아 볼 수 있다.

| 이름 | 사례 | 휴면 |
|---|---|---|
| 한가람 | 200일간 로그인 없음, 참여 이력 없음 | 표시 |
| 이새봄 | 어제 로그인, 참여 이력 없음 | 표시 안 함 |
| 정다온 | 300일 전 등록, 7일 전 완주 | 표시 안 함 |
| 최한결 | 30일 전 하차 | 표시 안 함 |
| 김해솔 | 200일 전 완주, 200일간 로그인 없음 | 표시 |
| 박새별 | 7일 전 가입 | 표시 안 함 |
| 윤이든 · 서하람 | 참여 중 · 일시 중단 | 표시 안 함 |
| 오누리 · 임라온 | 로그인일 · 참여 종료일 미확인 | 표시 안 함 |

Alex는 최근 백오피스 로그인, Robin은 200일간 로그인·참여가 없는 캡틴 예시다.

## 실제 코드 반영

서버는 기존 `ACCOUNT_IDENTITY.LAST_LOGIN_AT`의 최댓값과 명부의 `JOINED_AT`·`LEFT_AT`, 스터디 `END_AT`으로 판정한다. 새 DB 컬럼이나 기존 기록 보정은 필요하지 않다. 필요한 날짜가 없는 과거 기록은 휴면 표시를 보류한다. 프론트는 서버의 `dormant` 값을 그대로 표시하며 목록 안내와 툴팁을 제공한다.

목록 정렬과 권한은 그대로다.
