# GA4·Amplitude 회원 식별과 중단·삭제 처리

## 미리 알아야 할 것

GA4와 Amplitude는 서비스 이용 흐름을 분석하는 도구다. 브라우저뿐 아니라 서버도 이벤트를 보낸다.
HMAC은 서버만 아는 비밀키로 회원번호를 분석용 값으로 바꾸는 방식이다. 이름표를 바꾼 것과 같아서 계정과 연결 가능하며 개인정보로 관리한다.

## 정해진 것

- 원문 회원번호 대신 한 번 만들어 저장한 HMAC ID를 사용한다. ACCOUNT는 바꾸지 않고 ACCOUNT_ANALYTICS 한 테이블에 수집 중단·삭제 진행을 보관한다.
- 문의 화면에는 버튼을 추가하지 않는다. 플레이그라운드 시안도 제거한다. 담당자는 본인 요청을 확인하고 ADMIN 전용 API로 실행하며 기존 문의 상세 API에서 진행을 확인한다.
- 별도 삭제 작업 테이블·키 버전 컬럼·요청 번호·다음 실행 시각은 제거한다. GA 브라우저 번호는 삭제 범위 검증 전까지 유지한다.
- 서버는 중단 상태를 확인한다. 브라우저는 30초마다 재확인하고 허용 상태는 45초 후 만료한다.
- 탈퇴 후 30일 대기는 없다. 열린 탭의 중단 반영을 고려해 90초 후 첫 삭제를 요청하고, 실패·진행 조회는 기존 일일 cleanup에서 이어간다.
- GA4의 전체 식별자 삭제 접수와 Amplitude 완료 확인 후 로컬 식별자를 정리한다. 활성 회원은 중단 상태만 남기고 탈퇴 회원은 분석 행을 제거한다. **GA4 접수를 실제 삭제 완료로 표시하지 않는다.**
- Clarity는 이번 변경에 포함하지 않는다.

## 담당자 할 일

개발 담당자는 [운영 문서](../analytics-privacy.md)에 따라 비밀키·삭제 권한을 준비하고 실제 테스트 계정으로 외부 연동을 확인한다. 미처리 건이 있는 동안 분석 프로젝트 설정을 바꾸지 않는다.
문의 담당자는 중단 API를 실행하고 기존 문의로 답한다. 수집 중단과 외부 삭제 접수를 구분해서 안내한다. GA4 실제 완료 증빙이 필요한 경우 Google 지원 절차를 이용한다.
방침 담당자는 쿠키 거부만으로 분석에서 제외된다는 문구를 삭제하고 실제 배포 동작에 맞춘다. 30일 내 외부 삭제 완료를 보장하지 않는다.

## 처리방침 표현 정리 (2026-11-10)

이용자에게는 HMAC 대신 ‘회원번호를 변환한 분석용 식별자’로 한 번 설명한다. 수집 항목·목적·보관기간·국외이전, 문의 및 이메일 접수, 탈퇴·중단 시 삭제 절차, 새 브라우저에서 로그인 후 설정이 적용되는 범위는 유지한다. 재시도·진행 상태·식별자 정리 등 내부 처리 방식은 [운영 문서](../analytics-privacy.md)에 두고 공개 방침에서는 반복 설명을 줄인다. 실제 수집·중단·삭제 동작은 바꾸지 않는다.
