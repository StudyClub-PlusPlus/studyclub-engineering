# 대시보드는 현재 프로필 시간대를 우선한다

## 미리 알아야 할 것

프로필 시간대는 회원이 가입하거나 내 정보 수정에서 선택한 지역이다. 브라우저 시간대는 접속한 기기의 설정이다. 대시보드의 조회자 시간대는 날짜를 표시하고 출석 기록을 주 단위로 나누는 기준이다. 같은 모임을 어느 지역 달력에 적는지 고르는 것과 같다.

## 정해진 것

- 현재 프로필 → 브라우저 → 서울 순서로 선택한다. 프로필이 있으면 기기 설정으로 덮어쓰지 않는다.
- 서버는 요청마다 최신 프로필을 읽는다. 프론트가 전달한 브라우저 값은 프로필이 없거나 유효하지 않을 때만 사용한다.
- 갱신 시각·모집 날짜·D-day·전주 대비·12주 차트에 같은 기준을 적용한다. 한 주는 선택한 시간대의 월요일 00:00부터다.
- 프로필 변경은 다음 대시보드 진입·새로고침 때 반영한다. 열린 화면은 자동 갱신하지 않는다.
- 프로필 DB 조회 실패는 요청 실패로 처리한다. 프로필 값 누락으로 간주하지 않는다. 명시한 무효 Query는 기존처럼 400으로 거절한다.
- 전기간 출석률의 계산식과 모집 종료 시각은 유지한다. 시간대 분포는 각 크루의 설정값으로 분류한다.

## 그래서 나는 뭘 해야 하나

- 개발: API 응답의 `timeZone`을 최종 기준으로 사용한다. 요청의 `timeZone`은 브라우저 대체값이다.
- 검수: 프로필·브라우저 불일치, 프로필 누락, 설정 변경 후 재진입, 월요일·서머타임 경계를 확인한다.
- 기획: 표시와 집계 기준은 [대시보드 명세](../../specs/dashboard/spec.md)를 확인한다.
