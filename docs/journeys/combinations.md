# 조합표 — 일정 패턴 × 상황

> 작성: 2026-09-28 · 상태: **제안** · 페르소나는 [personas](./personas.md), 여정은 [journeys](./journeys.md)
> 회차·출석 규칙은 [회차](../flows/meeting.md) · [출석](../flows/attendance.md), 화면은 [와이어프레임](../../specs/meeting/wireframes/index.html)

## 한 줄 결론

**화면이 달라지는 조합만 와이어프레임을 그린다.** 54칸 중 새로 그릴 곳은 6장(11~16)이면 되고, 나머지는 기존 01~10 이 그대로 덮는다.
패턴이 달라도 **모델은 하나**다 — 달라지는 것은 반복 일정의 요일·간격과 출석 방식뿐이고, 화면이 달라지는 곳은 "칩이 너무 많다(매일)", "반이 둘이다(분반)", "한 칸이 한 주가 아니다(여러 요일·격주)" 세 가지 원인으로 모인다.

## 칸별 — 무엇이 다른가

### ● 새로 그리는 것

| 와이어프레임 | 칸 | 왜 기존으로 안 되나 |
|---|---|---|
| **11 분반 2개** | B1 · B3 · B7 | 반이 둘이면 ① 만들기를 반마다 해야 하고 ② 추석 같은 **공동 휴강**을 두 반에 한 번에 걸어야 하고 ③ 크루가 이번 주만 다른 반에 나오는 경우가 있다. 반 선택 드롭다운 하나로는 안 보인다 |
| **12 여러 요일 · 격주** | C4 · D1 · D4 | 미루기의 "한 칸" 이 한 주가 아니다. 월·수·금에서 한 칸은 수→금, 격주에서 한 칸은 2주. 운영자가 원하는 건 대개 **"이번 주 통째로"** 다. 격주는 만들 때 **어느 주가 쉬는 주인지** 보여야 한다 |
| **13 매일 클럽** | E2 | 한 달 31칩이면 달력이 칩으로 덮인다. 출석 격자는 31열이라 가로로 넘친다. 방식(공부 시간·인증)에 따라 칸 내용도 다르다 |
| **14 여러 주 쉬기** | A5 · B5 · E5 | 방학·연휴는 **기간**이다. 칩을 하나씩 고르면 매일 클럽 2주 = 14번 클릭. 날짜 범위로 고르고 휴강/미루기를 고른다 |
| **15 클럽 다음 기수** | E9 | 반·반복 일정 복사 + 명부 이월 + 펼치기가 한 번에 일어난다. 무엇이 넘어가고 무엇이 안 넘어가는지 확인이 필요하다 |
| **16 크루 개인 불참 · 잠시 쉼** | A8 · C7 | 크루가 **여러 회차 휴가를 한 번에**(출장 1주 = 월·수·금 3회) 내거나, **몇 주 쉬기**(PAUSED)를 신청하는 화면이 없다. 운영자 격자에 쉬는 구간이 보여야 한다 |

### ○ 기존으로 충분한 것 — 차이만 적는다

| 칸 | 차이 |
|---|---|
| A 전부 | 01~10 이 A 를 예시로 그렸다 |
| B2 · B6 | 반 선택 드롭다운으로 반을 바꾸면 A 와 같다. 크루는 **자기 반 시간대**로 본다 (미주반은 PT) |
| B4 | 미루기는 반마다 따로. 두 반을 같이 미루는 일은 드물다 — 필요하면 반마다 한 번씩 |
| C1 · D1(요일) | 04 의 요일 칩을 여러 개 켜면 된다. 격주의 기준 주만 12 에서 |
| E1 | 04 의 「매일」 단축. 끝은 날짜(월말)가 미리 채워진다 |
| E3 · E6 | 하루짜리 회차 하나를 휴강·변경 — 02 와 같다 |
| E4 | 매일 클럽의 미루기는 거의 없다. 하면 월말을 넘는 회차가 **떨어진다** (06 영향 요약의 "기수 밖 삭제" 줄) |
| E7 | 09 ⑤ 휴가. 매일 클럽에서 며칠 연속이면 16 의 여러 회차 휴가 |
| F 전부 | 단건은 반복 일정이 없을 뿐 회차 하나는 똑같다. 미루기만 안 된다 (02 단건 팝오버에 이미 적음) |

## 조합에서 나온 것 — 스펙·결정

조합을 채우다 기존 설계로 안 풀리는 것이 셋 나왔다.

| # | 무엇 | 어디서 | 제안 | 반영 |
|---|---|---|---|---|
| 1 | **여러 반 공동 휴강** — 추석 주에 목요일반·미주반 둘 다 | B3 · B5 | 스터디 범위 일괄 수정 `PATCH /api/studies/{studyId}/meetings` (반 여러 개의 회차를 한 트랜잭션으로) | [meeting spec 미확정](../../specs/meeting/spec.md#미확정) |
| 2 | **이번만 다른 반 출석** — 목요일반 크루가 이번 주만 미주반 회차에 | B7 | ERD 는 이미 "실제 참석한 반" 을 칸에 두도록 적어 둠. 크루 화면에 「이번 주 다른 반으로」 를 둘지 결정. **디스코드 출석 스펙은 자기 반에만 찍는다** — MVP 는 그쪽을 따른다 | [결정 11](../flows/README.md#사람이-정해야-할-것) · [관계 R3](../flows/README.md#먼저-머지된-것과의-관계--맞춰야-할-곳) |
| 3 | **잠시 쉼의 기간** — "11월 한 달 쉼" 을 알아야 그 기간 회차를 분모에서 뺀다 | A8 · E8 | 명부에 쉼 이력(시작·끝) — 지금은 상태값 하나뿐 | [결정 7](../flows/README.md#사람이-정해야-할-것) |

기간 쉬기(14)·여러 회차 휴가(16)·격주 미루기(12)는 **API 변경이 없다** — 화면이 기간 안의 회차를 골라 기존 휴강·미루기·휴가 API 로 보낸다.
