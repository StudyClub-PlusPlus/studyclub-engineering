# 페르소나 — 일정 패턴별

> 작성: 2026-09-28 · 상태: **제안**
> **역할** 페르소나(캡틴 · 네비게이터 · 크루)는 기획 레포의 `planning/personas/` 가 정본이다. 이 문서는 그 위에 **일정 패턴** 축을 얹는다 — 같은 네비게이터라도 주 1회 스터디와 매일 클럽은 하는 일이 다르다.
> 이름은 모두 가상이다.

## 크루

### 수아 — 주 1회 스터디 · 직장인

| | |
|---|---|
| **상황** | 시스템 디자인 1기 (매주 목 20:00 · 8회). 퇴근 후 노트북으로 들어간다 |
| **목표** | 8회 중 빠지지 않고 완주. 빠질 거면 미리 알리고 싶다 |
| **페인** | 야근이 한 달에 한두 번 — 휴가를 내야 하는데 어디서 하는지 모른다. 일정이 바뀐 걸 디스코드 스크롤로만 알아서 놓친다 |
| **쓰는 화면** | 09 체크인 카드 · 09⑤ 휴가 · 08 일정 변경 알림 |
| **성공 신호** | "휴가 낸 날이 옮겨지면 알려줘서 다시 냈다" |

### 시우 — 분반 · 미국 서부

| | |
|---|---|
| **상황** | 알고리즘 스터디 미주반 (PT 수 19:00 = KST 목 11:00·12:00). 한국 공지가 한국 시각으로만 온다 |
| **목표** | 내 시각으로 일정을 보고 싶다. 이번 주만 한국반에 들어가도 출석이 됐으면 |
| **페인** | 서머타임이 바뀌는 주에 한국 시각 공지를 보고 한 시간 틀린다 |
| **쓰는 화면** | 09 (자기 반 시간대) · 11 이번만 다른 반 |

### 지민 — 매일 클럽 · 공부 시간

| | |
|---|---|
| **상황** | WEEKLY X 10월 기수. 매일 공부 시간을 적는다 — 지금은 구글시트 |
| **목표** | 하루 한 번, 10초 안에 적고 끝. 월이 바뀌어도 다시 신청하지 않기 |
| **페인** | 시트 칸을 찾아 내려가야 한다. 잊은 날이 결석인지 0분인지 애매하다 |
| **쓰는 화면** | 09 클럽 카드(공부 시간) · 13 매일 클럽 · 15 다음 기수(이월) |
| **이 사람이 웹 출석을 거부하는 조건** | 시트보다 한 번이라도 더 누르면 안 쓴다 — [클럽 MVP 논의](../flows/README.md#왜--무엇을-풀어야-하나) |
