# adr — 굳은 설계 결정

번호는 시간순, **재사용하지 않는다.** 뒤집을 때 지우지 않는다 — 상태를 `대체됨(→ NNNN)` 으로 바꾸고 새로 쓴다.
fleet 전체 규칙은 여기가 아니라 하네스 decisions, 기획 이유(왜 만드나)는 zapp PRD.

## 양식 — `NNNN-<주제>.md`

```markdown
---
번호: NNNN
상태: 제안 | 결정됨 | 대체됨(→ NNNN)
날짜: YYYY-MM-DD
올라온 곳: share/YYYY-MM-DD-<주제>.md · PR #NNN
---
# <결정 한 문장>

## 배경        무엇이 문제였나 (숫자가 있으면 숫자)
## 결정
## 버린 대안    무엇을, 왜 안 했나
## 결과        무엇이 쉬워지고 무엇이 어려워지나 — 나쁜 쪽도
```
