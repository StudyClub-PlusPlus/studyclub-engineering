# 회차 설정 UI — 캘린더처럼

> 작성: 2026-09-28 · 상태: **제안 (미결정)** · 모델·규칙은 [회차](./meeting.md), 전체 그림은 [README](./README.md)
> 대상: 백오피스(캡틴·네비게이터). 크루 화면은 [§8](#8-크루에게-보이는-것)에서 짧게.
> **와이어프레임**: [specs/meeting/wireframes](../../specs/meeting/wireframes/index.html) (브라우저로 연다) · API: [meeting spec](../../specs/meeting/spec.md)

## 한 줄 결론

**구글 캘린더를 아는 사람이 설명 없이 쓰는 화면.** 달력에서 반복 일정을 만들고, 회차를 눌러 옮기고·휴강하고·지우고, 반복 일정은 "이 회차만 / 이후 / 모두" 범위를 골라 고친다.
캘린더와 다른 것은 셋뿐이다 — **지난 회차는 안 바뀐다 · 기본은 삭제가 아니라 휴강 · 미루기가 있다.**

## 캘린더 조작 ↔ 회차 액션

| 캘린더에서 하던 것 | 여기서 | 회차 액션 ([회차 §4](./meeting.md#4-회차-액션--일정은-틀어진다)) |
|---|---|---|
| 반복 일정 만들기 | 「+ 반복 일정」 | 반복 일정 만들기 + 펼치기 |
| 빈 날짜 클릭 → 일정 만들기 | 같음 | 추가 (단건) |
| 일정을 다른 날로 끌기 | 같음 | 일정 변경 (이 회차만) |
| 반복 일정 하나 수정 → "이 일정" | 같음 | 일정 변경 → 예외가 된다 |
| 반복 일정 수정 → "이 일정 및 이후" | 같음 | 반복 일정 나누기 |
| 반복 일정 수정 → "모든 일정" | 같음, **단 지난 회차는 그대로** | 반복 일정 수정 |
| 삭제 → "이 일정" | **휴강** (기록 없으면 「완전히 삭제」도) | 휴강 / 삭제 |
| 삭제 → "이 일정 및 이후" | 같음 — 조기 종료 | 반복 일정 끝내기 |
| 없음 | **미루기** | 미루기 |
| 없음 | **여러 개 선택 → 한 번에** | 휴강 · 미루기 · 시각 변경 · 삭제 |

## 1. 어디에 있나

백오피스 스터디 상세의 **「회차」 탭** (출석 탭 옆).

| 탭 | 축 | 하는 일 |
|---|---|---|
| 회차 | **시간** — 달력 | 언제 모이나를 만들고 고친다 |
| 출석 | **사람 × 회차** — 격자 | 누가 왔나를 본다·고친다 |

출석 격자의 **열 머리(회차)를 눌러도 같은 팝오버**가 뜬다 ([§3](#3-회차를-누르면--팝오버)). 출석을 보다가 "이 회차 휴강" 을 하러 탭을 옮길 필요가 없다.

## 2. 화면

```
┌ 스터디 상세 · 시스템 디자인 1기 ───────────────────────────────────────────────┐
│ 크루 │ [회차] │ 출석 │ 정보                                                   │
├──────────────────────────────────────────────────────────────────────────────┤
│ 반 [목요일반 ▾]   ◀ 2026년 10월 ▶   [달력 | 목록]        [+ 반복 일정] [선택] │
├──────────────────────────────────────────────────────┬───────────────────────┤
│  월    화    수    목            금    토    일        │ 반복 일정              │
│                    1                                  │ ┌───────────────────┐ │
│                    ● 1회 20:00                        │ │ 매주 목 20:00~22:00 │ │
│                    ✓ 닫힘                              │ │ 10/1 ~ 11/19 · 8회   │ │
│  5     6     7     8                                  │ │ [수정] [끝내기]      │ │
│                    ● 2회 20:00                        │ └───────────────────┘ │
│  12    13    14    15                                 │                       │
│                    ● 3회 20:00  ← 오늘, 열림           │ 단건 회차              │
│  19    20    21    22                                 │  11/28 토 14:00 특강   │
│                    ○ 4회 20:00                        │                       │
│  26    27    28    29                                 │ 시간대: Asia/Seoul     │
│                    ○ 5회 20:00                        │ (반 설정에서 변경)      │
└──────────────────────────────────────────────────────┴───────────────────────┘
```

- **달력 보기**가 기본, **목록 보기**는 모바일·인쇄용 (날짜 · 번호 · 시각 · 상태 한 줄씩).
- 시각은 **반 시간대**로 보여주고 헤더에 밝힌다 ([POL-0006](../../01-planning/_registry/policies/POL-0006-timezone.md)). 보는 사람 시간대가 다르면 칩에 작게 병기한다 — `20:00 (PT 04:00)`.
- 오른쪽 패널에 이 반의 **반복 일정 목록**. 반 하나에 여러 개일 수 있다 (정규 + 격주 특강, 또는 "이후" 수정으로 나뉜 것).

### 칩 모양 — 상태

| 상태 | 칩 | 드래그 |
|---|---|---|
| 예정 | `○ 4회 20:00` | ✓ |
| 열림 (지금 진행 중) | `● 3회 20:00` 강조 테두리 | ✗ |
| 닫힘 | `✓ 1회` 흐리게 | ✗ |
| 예외 (옮긴 회차) | `○ 4회 20:00` + `변경` 배지, 원래 날짜엔 점선 유령 칩 | ✓ |
| 휴강 | ~~`4회 20:00`~~ 취소선 + `휴강` | ✗ |
| 단건 회차 | 반복 아이콘 없음 | ✓ |

## 3. 회차를 누르면 — 팝오버

```
┌ 4회차 · 10/22(목) 20:00 ~ 22:00 ─────────┐
│ 매주 목 반복 일정                          │
│ 출석 기록 없음 · 휴가 1건 (수아)            │
│                                          │
│ [일정 변경]  [휴강]  [여기서부터 미루기]     │
│ ⋯ 완전히 삭제 · 되돌리기                   │
└──────────────────────────────────────────┘
```

상태에 따라 버튼이 다르다 ([회차 §4-3](./meeting.md#4-3-언제-무엇을-할-수-있나)).

| 상태 | 보이는 버튼 |
|---|---|
| 예정 | 일정 변경 · 휴강 · 여기서부터 미루기 · (기록 없으면) 완전히 삭제 |
| 열림 | 늦게 시작 (시각만) · 휴강 |
| 닫힘 | 휴강 (사후) |
| 휴강 | 되돌리기 |
| 예외 | 위 + 「원래 일정으로」 |

## 4. 범위를 묻는 때

반복 일정에서 나온 회차의 **요일·시각을 바꾸거나 지울 때만** 묻는다. 캘린더와 같은 3지선다다.

```
┌ 반복 일정을 수정합니다 ─────────────┐
│ ◉ 이 회차만                         │
│ ○ 이 회차 및 이후                    │
│ ○ 모든 회차 (지난 회차는 그대로)       │
│                      [취소] [다음]   │
└────────────────────────────────────┘
```

| 조작 | 묻나 | 이유 |
|---|---|---|
| 팝오버에서 요일·시각 수정 | **묻는다** | "이번만" 인지 "앞으로" 인지 화면이 알 수 없다 |
| 팝오버에서 삭제 | **묻는다** | 이 회차만 = 휴강 / 이후 = 조기 종료 |
| 드래그로 옮기기 | 안 묻는다 — **이 회차만** | 끄는 건 "이번만" 이다. 캘린더도 끌고 나서 묻지만, 매번 묻는 건 귀찮다는 불만이 많다 |
| 휴강 · 미루기 · 되돌리기 | 안 묻는다 | 정의부터 이 회차(들)만이다 |
| 오른쪽 패널 「수정」 | 안 묻는다 — **모든 회차** | 반복 일정 자체를 연 것이다 |

## 5. 반복 일정 만들기·수정 — 패널

```
┌ 반복 일정 ─────────────────────────────────────────┐
│ 반복     (◉ 매주) (○ 격주) (○ 매일)                   │
│ 요일     [월][화][수][■목][금][토][일]                 │
│ 시작일   [2026-10-01]                                │
│ 끝       (◉ 8 회) (○ 날짜까지 [2026-10-31])            │
│ 시각     [20:00] ~ [22:00]   반 시간대 Asia/Seoul     │
│                                                    │
│ ▸ 10/1 · 8 · 15 · 22 · 29 · 11/5 · 12 · 19          │
│   8회 · 10/1 ~ 11/19 · 목 20:00~22:00                │
│ ⚠ 11/28 특강과 겹치는 날 없음                          │
│                                  [취소] [만들기]     │
└────────────────────────────────────────────────────┘
```

- 입력을 바꾸는 즉시 **달력에 점선 유령 칩**으로 미리 보인다. 서버의 `dryRun` 과 같은 결과를 보여준다 — 화면이 따로 계산하지 않는다 (펼치기 로직이 두 벌이 되면 어긋난다).
- 「매일」 은 요일 7개를 한 번에 켜는 단축이다. 「격주」 는 `INTERVAL_WEEKS=2`.
- 끝은 **회수 또는 날짜** 둘 중 하나. 클럽 새 기수는 날짜(월말)가 미리 채워져 있다.
- 시간대는 여기서 고르지 않는다 — 반 설정이다. 반복 일정마다 시간대가 다르면 같은 반인데 기준 시각이 둘이 된다.
- 요일·시각을 바꾸는 저장은 [§4](#4-범위를-묻는-때)의 범위를 거친다.

## 6. 여러 개 선택

「선택」 을 누르거나 **Shift+클릭**으로 칩 여러 개를 고르면 하단에 액션 바가 뜬다.

```
┌──────────────────────────────────────────────────────────────┐
│ 3개 선택 (10/1 · 10/8 · 10/15)   [휴강] [미루기] [시각 변경] [삭제] [×] │
└──────────────────────────────────────────────────────────────┘
```

| 액션 | 선택 조건 | 예 |
|---|---|---|
| 휴강 | 아무 상태나 | 추석 연휴 두 주 |
| 미루기 | 모두 예정 · 반복 일정에서 나온 것 | 10/22 · 10/29 두 주 쉬고 뒤로 |
| 시각 변경 | 모두 예정 | 11월 회차만 21:00 |
| 삭제 | 모두 출석 기록 없음 | 잘못 만든 회차 |

조건이 안 맞는 버튼은 흐리게 두고, 누르면 이유를 한 줄 보여준다 ("10/15 는 이미 열린 회차라 미룰 수 없어요").

## 7. 확정 전 — 영향 요약

**여러 회차가 바뀌거나 날짜가 옮겨지는 액션은 한 번 멈춘다.** 같은 요약 박스를 쓴다. 회차 하나 휴강은 사유 입력만 받는다.

```
┌ 이렇게 바뀝니다 ──────────────────────────────────┐
│ 회차 5개가 한 주씩 뒤로  10/22~11/19 → 10/29~11/26   │
│ 끝                      11/19 → 11/26              │
│   □ 기수 종료일도 11/26 으로 늘리기                   │
│ 휴가 1건이 풀립니다      수아 · 10/22                 │
│ 알림                    크루 7명에게 「일정 변경」      │
│ 사유 (크루에게 보임)     [강사 사정              ]    │
│                                  [취소] [확정]     │
└──────────────────────────────────────────────────┘
```

| 줄 | 언제 보이나 |
|---|---|
| 바뀌는 회차 · 끝 | 미루기 · 반복 일정 수정 · 여러 개 일정 변경 |
| 남긴 회차 | 반복 일정 수정에서 예외·기록 있는 회차를 건드리지 않았을 때 |
| 떨어지는 회차 | `UNTIL` 반복 일정을 미뤄 기수 밖으로 나갈 때 |
| 풀리는 휴가 | 날짜가 바뀌는 회차에 본인 휴가가 있을 때 |
| 이미 체크인한 사람 | 열린 회차를 휴강할 때 |
| 알림 | 크루에게 보이는 변경 전부 |

드래그 한 번(예정 회차 1개, 휴가 없음)은 요약 없이 바로 저장하고 토스트로 알린다 — 「10/22 → 10/24 로 옮겼어요 · 되돌리기」. 크루 알림은 **토스트가 사라진 뒤(10초)** 보낸다 — 되돌렸는데 알림이 이미 나가 있으면 안 된다.

## 8. 크루에게 보이는 것

| 화면 | 표시 |
|---|---|
| 내 스터디 · 다음 회차 | 날짜·시각 + 바뀌었으면 `일정 변경` 배지와 사유 |
| 회차 목록 (펼침) | 휴강은 취소선으로 남는다. 옮긴 회차는 "원래 10/22" |
| 알림 | 반복 일정 수정·미루기는 **바뀐 회차를 한 알림에 묶어** 보낸다. 5개가 바뀌어도 알림은 1개 |

## 만들지 않는 것

| 안 만든다 | 이유 · 다시 볼 때 |
|---|---|
| 주간 시간 격자 보기 (시간 슬롯) | 반 하나의 회차는 하루 1개 안팎이다. 여러 반을 한 화면에 겹쳐 볼 때 필요해진다 |
| 여러 반 겹쳐 보기 | 캡틴이 기수 전체 일정을 한눈에 봐야 할 때 |
| 칩 끝을 끌어 길이 바꾸기 | 창 길이는 반복 일정 설정으로 충분하다 |
| 캘린더 라이브러리 (FullCalendar 등) | 월 달력은 이미 설치된 `date-fns` + 네이티브 드래그로 된다. 주간 시간 격자가 필요해지면 그때 |
| 크루용 캘린더 구독 (ICS) | **다음 후보 1순위.** 크루가 구글 캘린더에 구독하면 일정 변경이 자동 반영된다. 회차 행이 진실이라 피드 생성은 쉽다 |

## 시나리오 — 주 1회 스터디, 10/22 한 주 쉬기

| # | 운영자가 하는 일 | 화면 |
|---|---|---|
| 1 | 회차 탭 → 10/22 칩 클릭 | 팝오버: 휴가 1건(수아) 표시 |
| 2 | 「여기서부터 미루기」 | 달력에 10/22~11/19 칩이 한 칸씩 뒤로 간 유령 칩 |
| 3 | 영향 요약 확인 · 종료일 늘리기 체크 · 사유 입력 | [§7](#7-확정-전--영향-요약) 박스 |
| 4 | 확정 | 칩 이동 · 10/29 칩에 `변경` 배지 · 10/22 자리에 점선 유령 칩 · 크루 7명에게 알림 1개 |

같은 일을 "8회를 안 채워도 된다" 면 2에서 「휴강」 — 사유만 받고 끝난다. 크루에게 휴강 알림이 나간다.
