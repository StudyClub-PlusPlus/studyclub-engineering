# flows — 기능 여럿을 가로지르는 흐름

업로드·변환 파이프라인·인증 왕복처럼 **기능 하나에 안 담기는 경로**. 기능 하나의 계약은 `specs/<기능>/` — 여기서는 가리키고 베끼지 않는다.
그림(아티팩트)으로 설명했으면 같은 내용을 여기에 md 로 남기고 아티팩트 URL 을 적는다. 실측값은 날짜와 함께.

| 흐름 | 지나는 기능 | 갱신 |
|---|---|---|
| [이미지 업로드](image-upload.md) | 올리기 API · 프로필 사진 · 스터디 썸네일 · 탈퇴 · 정리 배치 | 새 용도를 붙일 때 |
| [디스코드 계정 연동](discord-link.md) | 신청 연동 창 · 연동 API · 출석체크 · role 부여 · 구글 로그인 콜백 규칙 | 연동 진입점을 늘릴 때 (가입 화면 DSC-03) |
