# flows — 기능 여럿을 가로지르는 흐름

업로드·변환 파이프라인·인증 왕복처럼 **기능 하나에 안 담기는 경로**. 기능 하나의 계약은 `specs/<기능>/` — 여기서는 가리키고 베끼지 않는다.
그림(아티팩트)으로 설명했으면 그 설명을 여기 md 본문에 옮긴다. 아티팩트 링크 대신 설명을 쓴다(팀원은 비공개 링크를 못 연다). 실측값은 날짜와 함께.

| 흐름 | 지나는 기능 | 갱신 |
|---|---|---|
| [이미지 업로드](image-upload.md) | 올리기 API · 프로필 사진 · 스터디 썸네일 · 탈퇴 · 정리 배치 | 새 용도를 붙일 때 |
| [웹 푸시](web-push.md) | 구독 · 서비스 워커 · 아웃박스 발송 · 푸시 서버 · iOS 설치 조건 | 알림 채널을 더하거나 stage 에서 확인할 때 |
| [디스코드 계정 연동](discord-link.md) | 신청 연동 창 · 연동 API · 출석체크 · role 부여 · 구글 로그인 콜백 규칙 | 연동 진입점을 늘릴 때 (가입 화면 DSC-03) |
| [beta 머지 큐](merge-queue.md) | PR → beta 머지 · 필수 검사(version-lint) · 브랜치 룰셋 | 필수 검사를 늘리거나 머지 방식을 바꿀 때 |
